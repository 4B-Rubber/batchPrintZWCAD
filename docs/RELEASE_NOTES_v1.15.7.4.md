# 批量打印插件 v1.15.7.4 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。图框块与通用型面板新增「对象扫描」，选择阶段按类型过滤并只识别选中对象，以加快图框识别。

## 对象扫描

- 图框块面板与通用型面板在「框选扫描」旁增加「对象扫描」。
- 选择阶段即过滤类型：图框块只允许块参照；通用型允许块参照与各类多段线，开启四线识别时还包括直线。
- 只扫描选中 ObjectId，不再遍历整张图；取消选择时现有清单不变。
- 保留原有「框选扫描」与「扫描当前图」范围对话框。

## 对象扫描右键

- 尚未左键拾取时右键：在光标处弹出紧凑扫描范围菜单。
  - 模型空间：当前模型 / 所有布局 / 模型+布局
  - 布局空间：模型空间 / 所有布局 / 模型+布局 / 当前布局名
- 已经左键点选或拉框后右键：确认当前选择（等价回车）。
- 命令入口仍是先打开面板，不强制先选对象。
