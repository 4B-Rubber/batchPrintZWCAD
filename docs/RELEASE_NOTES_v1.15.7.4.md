# 批量打印插件 v1.15.7.4 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。当前图扫描统一为「先对象过滤、再识别」：面板「框选扫描」用 GetSelection 按类型过滤，选中对象后扫描；未拾取时右键可选扫描范围。

## 框选扫描（统一入口）

- 图框块与通用型面板以「框选扫描」作为当前图扫描入口（原「扫描当前图」对话框与几何窗口框选入口已合并进该流程）。
- 选择阶段即过滤类型：图框块只允许块参照；通用型允许块参照与各类多段线，开启四线识别时还包括直线。
- 只扫描选中 ObjectId；取消选择时现有清单不变。
- 多文件批打仍先选 DWG 与模型/布局，不经过图面对象选择。

## 框选扫描右键

- 尚未左键拾取时右键：在光标处弹出紧凑扫描范围菜单。
  - 模型空间：当前模型 / 所有布局 / 模型+布局
  - 布局空间：模型空间 / 所有布局 / 模型+布局 / 当前布局名
- 已经左键点选或拉框后右键：确认当前选择（等价回车）。
- 命令入口仍是先打开面板，不强制先选对象。
