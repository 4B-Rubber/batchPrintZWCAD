# LA批量打印插件 v1.15.10.1 发布说明

本版本相对 **v1.15.10** 的补丁发布。适用于 ZWCAD、AutoCAD 2015–2024 与 AutoCAD 2025–2027。

## 相对 v1.15.10 的更新

### 通用型批打界面

- 移除通用型批打工具栏「图号重排」按钮（与 CTB 下拉重叠、工具栏被裁切导致 CTB 设置不可用）。
- CTB 嵌套网格、打印样式下拉、样式设置按钮与「开始打印」按钮统一 `VerticalAlignment="Center"`，改善工具栏垂直对齐。

### 多文件 / 按源文件输出路径

- 通用型批打按任务源 DWG 计算输出目录（`GetOutputDirectory(job.SourceFile)`），与图框型 `BatchPlotForm` 行为对齐；不再总是落到当前文档目录。
- 拆图确认与完成提示改为描述实际输出位置。

## 安装说明

与以往版本相同：按平台解压对应 ZIP，按说明 NETLOAD 或使用自动加载；升级时请先关闭已加载旧 DLL 的 CAD 进程后再替换文件。

## 完整变更

详见仓库 `main` 自 `v1.15.10` 至本 tag 的提交记录。
